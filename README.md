# GeoFields

A specialized web GIS application and analytical database designed to index, analyze, and visualize missing persons cases and search and rescue (SAR) patterns across U.S. National Parks and public lands.

🌐 **Live Interactive Application:** [https://tayaapril0613.github.io/GeoFields/](https://tayaapril0613.github.io/GeoFields/)

## 🗺️ Key Application Features

* **Interactive Web Map:** Multi-layer map engine supporting Topographic, Relief/Terrain, and High-Resolution Satellite imagery.
* **Incident Data Schema:** Standardized spatial data management structure for missing persons records.
* **Spatial Query Engine:** Real-time view bounds tracking and spatial filtering across public lands.
